 # Assignment 1 - What happens between typing a URL and seeing the page?
 
 When you enter a URL (e.g., [https://example.com](https://example.com)) into your browser, the browser first checks its local cache and queries DNS (Domain Name System) servers to resolve the domain name into an IP address. Once the IP address is obtained, your browser initiates a TCP/IP connection (and performs a TLS handshake for HTTPS) with the web server hosted at that IP address. The browser then sends an HTTP GET request for the web page, and the server responds with the HTML, CSS, JavaScript, and asset files. Finally, the browser’s rendering engine parses the HTML into a DOM tree, processes the CSS into a CSSOM tree, combines them into a render tree, and paints the webpage onto your screen.
